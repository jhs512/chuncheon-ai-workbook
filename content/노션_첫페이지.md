# 한전 AI 업무활용 실습교재

## 수업에서 다룬 핵심 내용

### 실습 환경 준비하기

ChatGPT는 **구글 계정으로 가입**합니다. 이번 교육에서는 파일과 도구를 함께 다루기 편한 **ChatGPT 데스크톱 앱**을 사용하며, 모든 실습은 **Codex 모드**로 진행합니다. Codex에서는 파일을 만들거나 수정하고, 명령을 실행하거나 연결된 도구를 사용할 수 있습니다.

**액션 승인은 전체 액세스로 설정합니다.** 먼저 **설정 → 일반 → 권한**에서 전체 액세스를 켠 다음, **채팅 입력창의 액션 승인 메뉴에서도 전체 액세스**를 선택합니다. 설정에서 해당 기능을 켜는 것과 현재 채팅에 적용하는 것은 별도입니다.

### 작업에 맞게 프로젝트와 채팅 선택하기

오래 이어지는 작업이나 같은 자료를 반복해서 사용하는 작업은 **프로젝트**에서 진행합니다. 간단하게 끝나는 작업은 **새 채팅**으로 시작합니다.

각 채팅에서는 **현재 작업 폴더**를 확인합니다. `Ctrl + ~`로 터미널을 열면 작업 위치를 확인할 수 있습니다. 이 단축키는 백틱 키를 사용합니다.

### 원하는 작업을 프롬프트로 구체화하기

요청을 어떻게 써야 할지 모르겠다면 AI에게 먼저 프롬프트 작성을 부탁합니다.

> ○○하고 싶은데, 프롬프트를 만들어 줘.

작업을 더 구체적으로 정하고 싶다면 필요한 조건을 질문하도록 요청합니다.

> ○○을 제대로 하려면 필요한 사항을 집요하게 물어봐 줘.

목적과 조건이 정리되면 **일단 작업을 시켜 봅니다.** 기본 기능으로 처리하지 못하는 부분이 확인되면, 그때 필요한 **스킬이나 MCP**를 추가합니다.

### 필요한 기능 추가하기

| 도구 | 활용할 수 있는 작업 |
|---|---|
| [CursorTouch/Windows-MCP](https://github.com/CursorTouch/Windows-MCP) | Windows 화면을 확인하고 앱을 조작하는 작업 |
| [imsebeom/hwpx](https://github.com/imsebeom/hwpx) | 한글 HWPX 문서를 만들고 편집·검증하는 작업 |
| [HyperFrames](https://github.com/heygen-com/hyperframes) | 정보를 전달하는 영상이나 설명 영상을 만드는 작업 |
| [mattpocock/skills](https://github.com/mattpocock/skills) | 프로그램을 개발하고 설계·검토하는 작업 |

### Gemini로 웹페이지와 자료 활용하기

**Chrome에 내장된 Gemini**는 보고 있는 웹페이지를 연결해 바로 질문할 때 사용합니다. **Live**를 이용하면 페이지를 보면서 음성으로 대화를 이어갈 수 있습니다.

**Gemini 노트북**은 자료를 바탕으로 내용을 정리하고 전달할 때 사용합니다. **오디오 개요**로 팟캐스트 형식의 음성 콘텐츠를 만들고, **동영상 개요**로 설명 영상을 만들 수 있습니다.

**기능 안내:** [액션 승인](https://learn.chatgpt.com/docs/permission-modes) · [프로젝트](https://learn.chatgpt.com/docs/projects?surface=app) · [단축키](https://learn.chatgpt.com/docs/reference/commands) · [Chrome의 Gemini](https://support.google.com/chrome/answer/16283624?hl=ko) · [오디오 개요](https://support.google.com/gemininotebook/answer/16212820?hl=ko) · [동영상 개요](https://support.google.com/gemininotebook/answer/16454555?hl=ko)
