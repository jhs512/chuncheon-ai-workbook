# 4. Gemini 업무 활용

**90분.** Chrome의 Gemini 웹에서 안내 문서·슬라이드·이미지, 노트북 자료 검토, 고객 답변 스킬, 계약 집계·Sheets 연동을 진행합니다.

각 실습의 **지금 준비할 파일 → 바로 할 일 → 요청 → 확인·수정** 순서로 진행합니다. 같은 내용의 Word·PDF·한글 파일은 한 형식만 고르며, 이 장에서는 PDF 첨부를 권장합니다.

| 시간 | 실습 | 완료 기준 |
|---|---|---|
| 0~25분 | GE01 문서·슬라이드·이미지 | 핵심 내용 일치, 실제 파일·크기 확인 |
| 25~45분 | GE02 노트북 | 자료 세 개 등록, 결론과 인용 대조, 두 진행자 오디오 생성 |
| 45~70분 | GE03 고객 답변 스킬 | 지침 저장·호출, 6건 답변과 FAQ 대조 |
| 70~90분 | GE04 계약 집계·Sheets | 합계 대사, 표 저장 범위·차트 확인 |

로그인한 Gemini 웹을 열어 두세요. 완성 예시는 직접 요청하고 결과를 확인한 뒤에 선택해서 봅니다.

## GE01. 고객안내 문서·슬라이드·이미지

**목표:** 하나의 브리프에서 의미가 일치하는 안내문 1쪽·슬라이드 5장·이미지 초안을 만듭니다.

### 지금 준비할 파일

| 필수 입력 | 용도 |
|---|---|
| [제작 브리프 PDF](../materials/04_gemini/문서PPT이미지_제작브리프_가상.pdf) **1개** | 안내문·슬라이드·이미지의 공통 조건과 넣지 말아야 할 정보를 확인합니다. |

### 바로 할 일

Gemini에서 **새 채팅 → 파일 추가 → 브리프 PDF 1개 첨부**를 합니다. 첨부된 파일명을 확인하세요. 이 파일을 세 작업에 공통으로 사용합니다.

### 안내문과 Google Docs

1. [Gemini 웹](https://gemini.google.com/)에서 새 채팅을 엽니다.
2. 파일 추가 메뉴에서 브리프 PDF 1개를 첨부합니다.
3. **Canvas**가 보이면 선택합니다.
4. 아래 **GE01D** 요청을 복사해 보냅니다.
5. 생성된 Canvas의 **내보내기 → Drive**를 선택합니다. 화면에 **Export to Docs**가 보이면 그 항목을 사용합니다.

![Canvas 안내문의 내보내기에서 Drive를 선택합니다.](../captures/annotated/04_gemini/GE01_03_export_menu.png)

6. 저장 알림의 **Drive에서 열기**를 선택합니다.

![Drive에 저장됨 알림을 확인하고 Drive에서 열기를 선택합니다.](../captures/annotated/04_gemini/GE01_04_drive_saved.png)

7. 상단에 **.MD**가 보이면 **파일 → Google Docs로 저장**을 선택합니다.

![상단에 .MD 표시가 있으면 파일 메뉴에서 Google Docs로 저장을 선택합니다.](../captures/annotated/04_gemini/GE01_06_convert_docs.png)

8. Google Docs에서 제목·본문이 보이는지 확인합니다.

![변환된 Google Docs에서 제목·본문과 저장 상태를 확인합니다.](../captures/annotated/04_gemini/GE01_07_native_docs.png)

9. **파일 → 페이지 설정 → 페이지 → A4**를 선택합니다.
10. PDF로 내려받아 페이지 수를 확인합니다.

**복사할 요청문:** [GE01D](../prompts/GE01D_고객안내문.txt)

```text
첨부 브리프만 근거로 '계획작업 안내문 확인 방법'을 주제로 고객안내 초안을 만들어 주세요.
A4 1쪽 안팎으로 제목/확인할 네 가지 항목/누락·불일치 시 다음 행동/문의 경로 확인란을 넣으세요.
실제 날짜·장소·공급 중단 여부·담당자·연락처·신청 링크·로고는 제공되지 않았습니다.
확인 필요로 남기세요.
어려운 약어와 설비 조작 설명을 쓰지 마세요.
한 문단에 한 가지 행동을 담아 짧게 쓰세요.
Canvas에서 편집할 수 있는 문서로 작성하고, 가능하면 Google Docs로 내보낼 수 있도록 준비해 주세요.
문장만 만든 상태와 실제 파일 생성 여부는 구분하세요.
```

**성공 확인:** 안내문에 네 가지 확인 항목·문의 경로 확인란이 있고, 내려받은 PDF가 A4 1쪽입니다. 확인 전에는 완료로 표시하지 않습니다.

### 슬라이드 5장과 Google Slides

**목표:** 확인한 안내문과 같은 뜻의 슬라이드 5장을 만듭니다.

**지금 준비할 파일:** 같은 [브리프 PDF](../materials/04_gemini/문서PPT이미지_제작브리프_가상.pdf) **1개**입니다. 앞에서 만든 안내문은 같은 대화의 결과를 사용합니다.

**바로 할 일:** 브리프가 첨부된 대화에서 아래 요청을 보냅니다. 새 채팅을 열었다면 PDF 1개를 다시 첨부하고 확인한 안내문을 붙여넣으세요.

1. 아래 **GE01S** 요청을 복사해 보냅니다.
2. 실제 슬라이드가 생성되면 **내보내기 → 프레젠테이션**을 선택합니다.

![실제 슬라이드 내보내기 메뉴. 프레젠테이션·PDF·PPTX를 구분합니다.](../captures/annotated/04_gemini/GE01_09_slides_export.png)

3. 생성 알림의 **Slides 열기**를 선택합니다.

![슬라이드 생성 알림에서 Slides 열기를 선택합니다.](../captures/annotated/04_gemini/GE01_10_slides_created.png)

4. Google Slides의 왼쪽 목록에서 **5장**인지 확인합니다.

![Google Slides 실물에서 1~5장 목록을 확인합니다.](../captures/annotated/04_gemini/GE01_11_google_slides.png)

5. 내려받을 파일이 필요하면 제공되는 다운로드 형식을 선택합니다.
6. 내려받은 파일을 다시 열어 내용을 확인합니다.

목차만 받은 상태는 슬라이드 파일 완성이 아닙니다. [Canvas 내보내기 안내](https://support.google.com/gemini/answer/16047321?hl=en)

**복사할 요청문:** [GE01S](../prompts/GE01S_고객안내슬라이드.txt)

```text
첨부 브리프와 확인한 안내문을 바탕으로 슬라이드 5장을 만들어 주세요.
1장 제목,
2장 확인할 네 항목,
3장 누락·불일치 예시,
4장 담당자에게 확인할 질문,
5장 확인된 내용만 안내한다는 마무리로 구성하세요.
장마다 제목과 핵심 내용 3개 이내로 쓰고 문서와 의미를 맞추세요.
미제공 날짜·연락처·링크·로고를 만들지 마세요.
Canvas에서 실제 슬라이드로 만들어 Google Slides로 내보낼 수 있게 준비해 주세요.
목차·텍스트만 만들었다면 슬라이드 파일 완성으로 표현하지 마세요.
```

**성공 확인:** 실제 Slides 파일이 5장이고 각 장 핵심은 3개 이내입니다. 안내문과 뜻이 일치하며 미제공 정보가 추가되지 않았습니다.

### 안내 이미지

**목표:** 네 가지 확인 항목을 읽기 쉬운 안내 이미지로 만듭니다.

**지금 준비할 파일:** 같은 [브리프 PDF](../materials/04_gemini/문서PPT이미지_제작브리프_가상.pdf) **1개**입니다. 완성 이미지 파일은 입력 준비물이 아닙니다.

**바로 할 일:** 브리프가 첨부된 대화에서 이미지 생성 기능을 선택합니다. 새 채팅이면 PDF 1개를 먼저 첨부하세요.

1. 이미지 생성 기능이 제공되면 선택합니다.
2. 아래 **GE01I** 요청을 복사해 보냅니다.
3. 생성 이미지를 열어 한글을 확인합니다.
4. 원본 다운로드 버튼을 선택합니다.

![실제 생성된 네 아이콘 이미지. 원본 다운로드 버튼을 선택하고 파일 크기를 확인합니다.](../captures/annotated/04_gemini/GE01_12_image_viewer.png)

5. 내려받은 파일의 **속성 → 자세히**에서 가로·세로 픽셀 수를 확인합니다.

**복사할 요청문:** [GE01I](../prompts/GE01I_고객안내이미지.txt)

```text
첨부 브리프에 맞춰 안내 이미지 초안을 만들어 주세요.
목표 크기는 가로 1600·세로 900픽셀입니다.
네 가지 확인 항목(안내 대상,예정 일시,안내 내용,문의 경로)을 상징하는 단순한 아이콘과 넓은 여백을 사용하세요.
긴 문장·실제 고객정보·시설 위치·기관 로고는 넣지 마세요.
이미지 속 한글이 정확하지 않으면 그림과 문구를 별도로 편집할 수 있게 제공하세요.
실제 생성 크기가 다르면 크기를 알려 주세요.
```

**성공 확인:** 네 항목명이 읽히고 실제 픽셀 수를 확인했습니다. 목표 1600×900과 다르면 목표와의 차이를 확인합니다.

### 확인·수정·저장

| 결과 | 확인할 것 |
|---|---|
| 안내문 | 네 가지 항목, 누락·불일치 시 다음 행동, 문의 경로 확인란 |
| 슬라이드 | 5장, 각 장 핵심 3개 이내, 문서와 같은 뜻 |
| 이미지 | 읽히는 글자, 넓은 여백, 실제 크기 |
| 공통 | 미제공 날짜·장소·연락처·링크·기관 로고를 만들지 않음 |

**복사할 요청문:** [GE01R](../prompts/GE01R_콘텐츠수정.txt)

```text
생성한 문서·슬라이드·이미지를 브리프와 대조해 주세요.
미제공 일정·장소·연락처·링크·공급 중단·복구·보상 정보가 있다면 제거하고 담당자 확인 필요로 바꾸세요.
네 가지 확인 항목을 유지하며 문서·슬라이드의 뜻을 맞추세요.
이미지 한글의 오탈자와 가독성을 확인하고 고친 부분을 목록으로 알려 주세요.
```


### 결과를 확인한 뒤 보내는 구체적인 수정 요청

**복사할 요청문:** [GE01DR](../prompts/GE01DR_안내문1쪽수정.txt)

```text
첫 안내문의 Google Docs PDF가 2쪽으로 나와 브리프의 A4 1쪽 목표를 만족하지 못했습니다.
첫 안내문 Canvas를 다시 열어 본문을 약 500~700자로 줄여 주세요.
중복 안내·구분선·과도한 빈 문단을 줄이세요.
제목, 네 가지 확인 항목(안내 대상·예정 일시·안내 내용·문의 경로), 누락·불일치 시 담당자 확인, 문의 경로 확인란은 유지하세요.
미제공 일정·장소·공급 중단·담당자·연락처·링크는 확인 필요로 남기고 실제 접수·재발송을 수행했다고 쓰지 마세요.
슬라이드는 별도 결과로 보존하고 안내문만 수정하세요.
A4 1쪽 여부는 제가 다시 PDF로 내보내 확인하므로 실제 확인 전 1쪽이라고 단정하지 마세요.
```

**복사할 요청문:** [GE01IR](../prompts/GE01IR_이미지표시보완.txt)

```text
방금 생성한 네 아이콘 배경을 유지하며 안내 이미지의 정확한 항목명을 보완해 주세요.
네 아이콘 아래에 왼쪽부터 '안내 대상', '예정 일시', '안내 내용', '문의 경로'를 넣으세요.
로고·실제 장소·연락처·일정은 추가하지 마세요.
한글 글자가 틀리거나 붙어 보이면 수정하고, 정확한 문구의 별도 편집이 필요하면 그 제한을 알려 주세요.
생성 원본과 편집본을 구분하고 실제 파일 크기를 확인하지 않고 1600×900이라고 단정하지 마세요.
```

**복사할 요청문:** [GE01SR](../prompts/GE01SR_슬라이드3묶음수정.txt)

```text
슬라이드 원본 5장은 유지하고 2장만 수정해 주세요.
2장이 네 확인 항목을 각각 제시해 '핵심 내용 3개 이내' 조건을 초과했습니다.
2장의 제목은 유지하고 핵심 항목을 세 묶음으로 재구성하세요: (1) 안내 대상·예정 일시 확인, (2) 안내 내용 확인, (3) 문의 경로 확인.
대상과 일시의 각 확인사항은 첫 묶음의 짧은 한 문장에 함께 포함하세요.
네 가지 원래 의미를 모두 유지하고 확인 필요 표기를 유지하세요.
1·3·4·5장과 미제공 일정·연락처는 바꾸지 마세요.
설명만 제시하지 말고 실제 프레젠테이션 Canvas의 2장을 편집해 주세요.
편집 전후 차이를 알려 주세요.
```

**저장:** 문서 링크와 내려받은 파일, Slides 링크와 파일, 이미지 파일을 각각 `GE01` 결과 폴더에 모읍니다.

**막혔을 때:** Canvas·내보내기가 제공되지 않으면 화면의 초안을 저장합니다. 한글 이미지가 틀리면 긴 문구를 빼고 문서·슬라이드에서 정확한 글자로 편집합니다.

### 결과를 비교하고 고치기

실제 예시에서는 첫 안내문이 **2쪽**이었습니다. 위 **GE01DR** 요청으로 줄인 본문을 Canvas에 반영하고, Google Docs의 **페이지 설정 → 페이지 → A4**를 선택한 뒤 PDF로 내려받아 **1쪽**인지 확인했습니다. AI가 “1쪽”이라고 답했는지만 보지 말고 직접 페이지 수를 확인하세요.

![축약 문서를 실제 Google Docs에 저장하고 A4로 설정한 최종 화면입니다.](../captures/annotated/04_gemini/GE01_15_final_a4_docs.png)

첫 슬라이드의 2장은 핵심 항목이 네 개여서 **3개 이내** 조건을 넘었습니다. **GE01SR** 요청으로 ‘대상·일시 / 안내 내용 / 문의 경로’ 세 묶음으로 수정했습니다. 전체 **5장**과 네 가지 원래 의미가 유지됐는지 확인하세요.

![새 Google Slides의 실제 2장입니다. 첫 카드에 대상·일시를 묶고 전체 항목을 세 카드로 정리했습니다.](../captures/annotated/04_gemini/GE01_20_slides_final_native.png)

이미지 뷰어의 **텍스트 도구**로 항목명을 보완하고, **GE01IR** 요청으로 다시 생성했습니다. 편집 화면의 저장이 입력창 첨부로 돌아온 경우에는 이미지 다운로드까지 확인하세요.


**성공 확인:** PDF 세 개가 등록됐고, 답변의 문서명·인용 문장·원문 내용이 맞습니다. 200건 기준과 300건 미승인 제안을 구분합니다.

```text
각 결론과 근거 문장을 짝지어 보여 주고, 노트북 자료 이외의 정보는 본 답변에서 제외하세요.
```

### 확인

인용에 연결된 문서명과 실제 내용을 대조합니다. 자료의 미확정 제안을 확정 조건으로 합치지 않습니다. 출처 링크가 열리는지와 인용된 항목이 결론을 뒷받침하는지를 따로 봅니다.

Gemini 노트북 자료는 Gemini 앱과 연동되지만, Gemini 앱의 답변에는 웹 등 다른 도구가 포함될 수 있습니다. 자료만 검토하는 요청에서는 외부 정보가 섞였는지 확인합니다. 노트북 Studio 기능이 모두 Gemini 채팅에 있는 것으로 가정하지 않습니다. [노트북 만들기](https://support.google.com/gemini/answer/16972047?co=GENIE.Platform%3DDesktop&hl=en), [두 화면의 범위 차이](https://support.google.com/gemininotebook/answer/17003757?hl=en)


**막혔을 때:** 메뉴가 없으면 제공 계정·지역·연동 상태를 확인합니다. 일반 채팅에 PDF를 첨부한 것과 노트북을 만든 것은 다릅니다.

**예시에서 확인할 점:** 노트북에 PDF 세 개를 등록한 뒤 답변에서 **제안요청서의 평가 사례 200건 / 회의록의 300건 확대 제안 / 미승인**을 구분했습니다. 실습용 FAQ **12개**는 정식 FAQ **80개** 납품 기준을 대신하지 않습니다. 인용의 파일명만 보지 말고 해당 PDF의 원문 문장을 열어 대조하세요. 입찰공고가 첨부되지 않았으므로 최종 제출기한은 이 자료만으로 확정하지 않습니다.

![문서 기재 200건·회의 제안 300건·미승인 상태를 나누어 확인합니다.](../captures/annotated/04_gemini/GE02_04_unapproved_proposal.png)


### 두 진행자 팟캐스트 만들기

검토한 PDF 세 개로 동료에게 설명할 한국어 오디오를 만듭니다. 답변 인용 검토를 마친 뒤, 같은 노트북의 자료를 사용합니다.

1. Gemini 앱 노트북 상단의 **Gemini Notebook** 링크를 눌러 전용 노트북을 엽니다. Studio가 보이는 화면이면 그대로 진행합니다.
2. **Sources**에서 FAQ·제안요청서·회의록 **PDF 세 개만 선택**합니다. 자동으로 연동된 Gemini 채팅이나 추가 자료가 있으면 선택을 해제합니다. 자료 자체를 삭제하지 않습니다.
3. **Studio → AI 오디오 오버뷰**를 누릅니다. 형식은 **심층 분석**, 언어는 **한국어**로 확인합니다. 심층 분석은 두 호스트가 대화하는 형식입니다.
![심층 분석·한국어·소스 3개를 확인합니다. 아래 요청문은 별도로 입력하세요.](../captures/annotated/04_gemini/GE02A_01_audio_settings.jpg)

4. **AI 호스트가 이 에피소드의 어떤 부분에 집중해야 하나요?**에 아래 요청을 붙여 넣습니다. 생성 전 **소스 3개**인지 확인하고 **지금 생성**을 누릅니다.

**복사할 요청문:** [GE02A](../prompts/GE02A_두진행자_팟캐스트.txt)

```text
등록한 FAQ·제안요청서·회의록 PDF 세 개만을 근거로, 한국어로 두 진행자가 대화하는 직원 교육용 팟캐스트를 만들어 주세요.
한 진행자는 고객안내 담당자, 다른 진행자는 문서 검토 담당자 관점에서 질문하고 설명해 주세요.
고객안내 전 확인 항목,
제안요청서의 평가 사례 200건과 회의록의 300건 확대 제안·미승인 상태,
실습용 FAQ 12개와 정식 납품 FAQ 80개의 차이를 다뤄 주세요.
요금·보상·복구 시각·최종 제출기한 등 자료에 없는 내용을 확정하지 말아 주세요.
마지막에 담당자 확인이 필요한 사항을 정리해 주세요.
```

5. 생성된 오디오 항목을 열어 **재생**합니다. 두 진행자가 한국어로 대화하는지, 200건과 미승인 300건·FAQ 12개와 80개를 구분하는지 듣고 PDF와 대조합니다. 생성 요청에 넣었다는 사실만으로 내용이 맞다고 판단하지 않습니다.
6. 결과의 **더보기 → 다운로드**로 오디오를 저장합니다. 잘못 말한 내용이 있으면 수정할 조건을 명확히 해 다시 생성합니다.

**성공 확인:** 오디오가 실제로 재생되고 두 진행자·한국어·원자료의 구분이 맞습니다. 파일이 내려받아졌는지도 확인합니다. 정확한 분량은 생성 결과에 따라 달라지므로 고정하지 않습니다.


**기다리는 동안:** 기존 GE02 인용 대조를 마무리합니다. 다음 실습으로 넘어갔다면 생성 후 돌아와 재생·저장을 확인하세요. 생성이 막히면 계정의 이용량과 기능 제공 상태를 확인합니다. 텍스트 대본만 나온 것은 오디오 생성 완료가 아닙니다.

[공식 AI 오디오 오버뷰 안내](https://support.google.com/gemininotebook/answer/16212820?hl=ko)

6. 만들기 또는 저장을 선택합니다.
7. 활성 목록에서 스킬 이름을 확인합니다.

![저장된 customer-reply-draft가 활성 목록에 표시되는지 확인합니다.](../captures/annotated/04_gemini/GE03_02_skill_active.png)

지침을 저장한 것과 참고파일이 포함된 것을 구분합니다. 추가 메뉴가 없으면 답변을 받는 새 채팅에 파일 2개를 첨부합니다.

**복사할 요청문:** [GE03I](../prompts/GE03I_고객답변스킬지침.txt)

```text
이 스킬은 고객 문의 답변 초안을 작성할 때 사용한다.
1. 첨부 FAQ와 사례를 읽고 문의 의도를 한 문장으로 요약한다.
2. 확인된 내용은 FAQ ID와 함께 안내하고, 미제공 정보는 담당자가 확인할 질문으로 남긴다.
```

### 결과가 틀리거나 파일을 읽지 못할 때

첫 실행은 CSV를 읽지 못하고 Python 코드 예시만 제시했습니다. **코드 예시만으로 실제 집계가 된 것은 아닙니다.** 파일명과 첨부 상태를 확인하고 다시 요청하세요. 실제 예시에서는 Pro 모드로 다시 요청해 집계표를 얻었습니다. 모드를 바꾸어도 계정에 따라 결과가 다를 수 있습니다.

**바로 고치기:** 실제 첨부한 CSV의 열과 숫자로 재분석을 요청합니다.

![실제 집계에 실패한 응답 뒤 CSV의 열과 숫자로 재분석을 요청합니다.](../captures/annotated/04_gemini/GE04_03_retry.png)

| 원자료와 대조할 항목 | 확인 값 |
|---|---|
| 계약 행·고유 계약번호 | 300건·300개, 중복 없음 |
| 전체 계약금액 | 12,608,000,000원 |
| 월별 건수 | 1~12월 각각 25건 |
| 월별·업무별·계약방법별 금액 | 각 그룹 합계가 전체 금액과 같음 |
| 계약방법별 건수·비중 | 수의 105건·35%, 일반 102건·34%, 제한 93건·31%; 합계 300건·100% |

응답이 제공하지 않은 Excel을 근거로 들면 **“실제 첨부한 CSV의 열과 계산식만 근거로 적어 주세요”**라고 수정 요청합니다. 계산값과 출처 표현을 따로 확인하세요.

![재실행에서 얻은 합계 교차검증 결과. 아래의 이전 XLSX 첨부 주장은 실제 제공 자료와 달라 수정 대상입니다.](../captures/annotated/04_gemini/GE04_04_totals.png)

**차트가 빈 화면이면:** Canvas 앱이 CSV를 읽지 못했다면 다음 순서로 진행하세요.

1. 원자료 CSV를 텍스트로 열어 전체를 복사합니다.
2. Canvas의 **CSV 원문 직접 붙여넣기**에 붙여넣습니다.

업무별 비중은 **금액**, 계약방법별 비중은 **건수** 기준입니다. 아래 차트 예시는 같은 자료가 기본으로 들어 있습니다.

두 차트는 **Canvas의 결과**이며, 앞서 내보낸 Sheets 합계 대사표의 차트가 아닙니다.
